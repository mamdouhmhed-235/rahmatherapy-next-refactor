## Phase 3 — Outcomes Snapshot

**Three directions proposed:**
1. Editorial Notebook — Notion / Things 3 / Arc aesthetic; restrained palette; spacious editorial calm
2. Operational Atlas — Linear project view / Notion Calendar aesthetic; committed palette with time-rail; balanced density
3. Tactile Card-Board — Trello / Linear Triage / Basecamp aesthetic; full palette with named statuses; data-dense at home

**Chosen direction: Direction 3 — Tactile Card-Board**

**Rationale captured:** The team's monday.com fluency is an asset to inherit (not a pattern to avoid). The earlier "generic / unprofessional / complicated" critique applied to the current Rahma admin codebase, not to monday.com. Card-Board transfers their muscle memory directly while Rahma's warm clinical palette, Cormorant Garamond on marquee numerals, varied card compositions, prominent avatars, dignified empty-state illustrations, and clinic-specific affordances (gender matching, mobile-first triage) raise the polish bar above any generic project tool. **Named rules introduced (six):**
1. **No-Gold-Text Rule** — both gold tokens fail WCAG 3:1 on canvas; gold is decoration only.
2. **Form Seam Rule** — input borders use `border-default` (oklch 55%, WCAG 1.4.11 ✓), not `border-subtle`.
3. **Named Status Rule** — every status badge requires bg tint + text + icon + label; colour alone is invalid.
4. **Tonal Lift Rule** — resting cards have no shadow; depth is surface lightness.
5. **Green-Tinted Shadow Rule** — all shadows tint to brand green; never generic black.
6. **Cormorant Exception** — Cormorant Garamond on numerals only; never body, titles, or labels.
